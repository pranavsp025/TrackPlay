# TrackPlay Agent System Rules

This repository uses a Spec-Driven Development (SDD) flow to ensure high quality, maintainability, and visual excellence.

## Behavior Constraints
- All development tasks MUST be spec-driven.
- Before executing any code changes, check for `SPEC.md` or the implementation plan. If one doesn't exist, create it.
- Follow the plan step-by-step and write verification steps.
- Verify each step using Vite build (`npm run build`) and type checking (`npx tsc`).

## Coding and Technology Stack Rules
- **Core**: React, Vite, TypeScript.
- **Styling**: Use Vanilla CSS for all components. Keep aesthetics rich, modern, and beautiful (dark mode, glassmorphism, smooth animations).
- **No Placeholders**: Use actual assets or generated images rather than placeholders.
- **Interactive Testing**: Verify user interactions and layouts locally.

## Universal Skills
- Leverage the `spec_driven` skill for all planning, execution, and verification phases.
- Leverage web search and official API documentations to get the correct endpoint structures and response formats.
